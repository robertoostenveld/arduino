# Arduino Uno keypad shield with 16x2 LCD 


## Menu structure

Main menu
├── Settings
│   ├── Brightness
│   └── Volume
├── Mode
│   ├── Manual
│   ├── Automatic
│   └── Calibration
└── Information
    ├── Version
    └── Counter
    
    
## Buttons 

UP / DOWN — navigate through menu items
RIGHT — enter submenu or edit a value
LEFT — go back one level
SELECT — return directly to the main menu (top level)
